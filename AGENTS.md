## Continuidade GitHub entre computadores

Antes de começar alterações solicitadas, confira git status e faça git fetch se o remoto estiver disponível. Integre mudanças remotas preservando trabalho local, inclusive alterações não commitadas e branches relevantes. Não use force push nem descarte histórico ou conteúdo para resolver conflitos.

Após verificações pertinentes, faça commits com a data real e mensagens claras e envie ao GitHub dentro do escopo autorizado pelo usuário. Informe conflitos e impedimentos concretos. Não publique credenciais, dados locais, dependências restauráveis ou resultados de compilação. Não execute operações contra produção apenas para validar código/publicação. Não configure monitoramento, tarefas agendadas ou envio automático em segundo plano.
